## Why this page

Only 2 shared results with the head term, and a different vendor set entirely:
Paycall, Yappr, Optimate, Zudu, SmartUp, plus a Globes article. The site targets
none of this vocabulary today, so it is uncontested ground *for us* — though not
uncontested generally.

"מזכירה וירטואלית" is how a clinic owner describes the need. "סוכן AI קולי" is
how a more technical buyer describes the technology. Same product, different
doorway.

## Outline

**H1** מה זה סוכן AI קולי ואיך הוא עובד

**H2 ההגדרה** — a voice agent chains speech recognition, a language model and
speech synthesis into one phone conversation. Explain it in two sentences, then
move on.

**H2 איך שיחה נראית מבפנים** — walk one real call end to end: ring, greeting and
recording disclosure, understanding the request, calendar lookup, booking,
logging. Concrete beats abstract, and this section is what gets cited by AI
assistants.

**H2 מה מבדיל סוכן קולי טוב מגרוע** — latency, interruption handling, memory
within the call, knowing when to hand off. Be specific about failure modes:
this is the section competitors skip.

**H2 עברית היא לא אנגלית** — RTL, mixed Hebrew-English speech, names, numbers,
accents. A genuine local differentiator and hard for a global vendor to fake.

**H2 איפה זה לא מתאים** — long judgement-heavy conversations, emotionally
sensitive calls, emergencies. Matches what `/terms` already commits to.

**H2 השלב הבא** — link to the homepage and pricing.

## Rules

- No invented latency or accuracy numbers. If you want a figure, measure your
  own system and say it is yours.
- Keep the emergency limitation consistent with `/terms`.
